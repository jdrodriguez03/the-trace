# Cómo contribuir

The Trace no recibe contribuciones externas por ahora: el código tiene todos los derechos reservados (ver [LICENSE](https://github.com/jdrodriguez03/the-trace/blob/main/LICENSE)). Si encuentras un error, abre un issue.

Para el equipo, las 5 reglas:

1. Nunca trabajes en `main`: una rama por tarea.
2. No cambies el trabajo de otra persona sin hablarlo antes.
3. No cambies el contrato (`api/app/schemas.py`) sin acordarlo.
4. Nunca subas una clave: revisa `git status` antes de cada commit.
5. Textos desde `content/`, cifras con los formatos y colores del tema.

Un PR se fusiona con la aprobación de otra persona del equipo y el CI en verde.
