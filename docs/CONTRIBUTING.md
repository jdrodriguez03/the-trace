# Cómo contribuir · Dueña: Isabela

The Trace no recibe contribuciones externas por ahora: el código tiene todos los derechos reservados (ver [LICENSE](../LICENSE)). Si encuentras un error, abre un issue.

Para el equipo, las 5 reglas (el detalle está en la guía rápida del proyecto privado):

1. Nunca trabajes en `main`: una rama por tarea (`ja/hoy-tarjeta`).
2. Solo edita tus carpetas (`.github/CODEOWNERS`).
3. No cambies el contrato (`api/app/schemas.py`) ni funciones de otros sin acordarlo.
4. Nunca subas una clave: revisa `git status` antes de cada commit.
5. Textos desde `content/`, cifras con los formatos y colores del tema.

Un PR se fusiona con la aprobación de cualquiera de los otros dos y el CI en verde.
