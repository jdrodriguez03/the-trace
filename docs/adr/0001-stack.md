# ADR-0001 · Stack

**Decisión propuesta:** API en Python con FastAPI, SQLModel y Alembic; base y login en Supabase; web en React + Vite + TypeScript con Tailwind y shadcn/ui.

**Por qué:** El equipo lee Python, donde está lo delicado; en la web se usa lo que la IA mejor conoce.
