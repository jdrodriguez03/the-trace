# ADR-0004 · Hosting

**Decisión propuesta:** Render: la web como sitio estático y la API como servicio, un solo entorno publicado desde main. La API puede pasar al plan Starter durante la prueba y la presentación.

**Por qué:** Despliega desde un repo privado con colaboradores y da vista previa por PR. Staging y producción separados quedan para la v2.
