# ADR-0005 · Cuota de IA

**Decisión propuesta:** 5 usos de IA al día por tipo (explicación de Hoy, Lectura y chat). Al pasar el límite, la API responde 429 AI_QUOTA y la web muestra la explicación de respaldo.

**Por qué:** Controla el gasto en Gemini y le da sentido a Trace+.
