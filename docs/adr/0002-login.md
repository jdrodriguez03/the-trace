# ADR-0002 · Login

**Decisión propuesta:** Supabase Auth: «Probar sin correo» = sesión de invitado; con correo = enlace mágico. La API verifica el token con las llaves públicas del proyecto.

**Por qué:** No se escribe manejo de contraseñas y quien entra con correo puede volver desde otro celular.
