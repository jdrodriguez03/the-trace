# web/ · Dueño: Juan Angel

La app que ve el usuario: React + Vite + TypeScript, Tailwind y shadcn/ui, mobile-first.

Partes de Isabela: `src/index.css` (tema), `src/components/`, `src/content/`, `src/lib/analytics.ts` y las pantallas `news-radar`, `market`, `account`, `monetization` y `galeria`.

- Correr: `npm run dev` → http://localhost:5173
- Tipos desde la API (con la API corriendo): `npm run api:types`
- Componentes de shadcn (solo Isabela): `npx shadcn@latest add <componente>`
